A single line of text: a quiet, earned moment of pride. A boy who has stammered through every reading lesson stands up, reads the final page without stopping once, and sits down changed, his shoulders straight for the first time all year. No trophy, no speech, just the effort and the moment it lands.

## How it works

`main.py` holds the line as a single string, checks it is one non-blank line of 1 to 240 characters, and writes it to `/output/entry.txt`, creating the directory if needed. It then reads the file back and confirms the written text matches the line exactly.

## How to run

```sh
python3 main.py
```

This writes `/output/entry.txt` (one line, 173 characters).
